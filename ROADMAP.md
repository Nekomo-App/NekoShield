# NekoShield Roadmap

> **Status: Coming Soon · In Development**

This roadmap tracks planned work. Items will only be marked complete after implementation and testing.

## 1. Planning & Architecture
- [ ] Define minimum and target Android versions
- [ ] Choose the app architecture and technology stack
- [ ] Document Android Private DNS, DoH, DoT, and VPN-based filtering limitations
- [ ] Define permission, privacy, and security requirements

## 2. Core Android App
- [ ] Create the Android mobile app foundation
- [ ] Build DNS provider selection and configuration screens
- [ ] Add custom DNS configuration management
- [ ] Add connection and DNS resolution diagnostics
- [ ] Handle invalid settings and unavailable DNS servers

## 3. Android TV
- [ ] Create TV-friendly layouts
- [ ] Support D-pad and remote-control navigation
- [ ] Verify focus states, readability, and accessibility
- [ ] Test on Android TV and Google TV devices

## 4. Providers & Filtering
- [ ] Verify provider endpoints and configuration requirements
- [ ] Add supported provider presets
- [ ] Investigate compatible ad, tracker, and domain filtering
- [ ] Add allowlist and blocklist controls where supported

## 5. Release Preparation
- [ ] Complete privacy and security review
- [ ] Test supported Android versions and device types
- [ ] Document known limitations
- [ ] Prepare release builds and installation instructions
- [ ] Publish the first stable release

Suggestions and bug reports can be submitted through GitHub Issues.
